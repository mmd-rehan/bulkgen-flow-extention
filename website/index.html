See it in 23 seconds

Set it up once. Then leave it.

Making twenty videos by hand means typing, waiting and downloading twenty times. BulkGen does that loop for you.

01

Paste your prompts

One prompt per line. Add character notes and a style line that get added to every prompt, so your cast stays consistent.

02

Choose your settings

Pick the model, clip length, aspect, download quality, how many run at once, and the most credits you will pay for one video.

03

Press Start

It sends each prompt, keeps your chosen number rendering at once, and marks each video ready. One click then downloads them all.

Everything the queue needs

Built from watching how Flow really behaves, not from guesses.

A queue that stays full

Keeps a set number of videos rendering at the same time. As one finishes, the next prompt goes in.

Character and style notes

Write who your character is once. The notes are added to every prompt so the look stays the same across clips.

A credit cap before every send

Reads Flow's own credit estimate before sending. If a video would cost more than the limit you set, nothing is sent.

One click downloads

Nothing downloads until you click. Then the videos of the project, or only those created between two dates, are saved one at a time, with live progress, as 720p original or 1080p upscaled into a BulkGen folder, numbered in prompt order like flow_001_title.mp4.

Retries, then a clear message

A failed download is retried the number of times you choose. After that it tells you which video to grab by hand and moves on.

Pause, stop and resume

Stop the run any time. If the page reloads, the queue picks up where it left off and stays on your project.

Pick the model

Reads the video models Flow offers and sets the one you choose. Seconds, resolution and aspect follow what that model allows.

Reference images

Add as many images as you have prompts. Image 1 goes with prompt 1, image 2 with prompt 2, for models that accept Ingredients.

Install in two minutes

BulkGen is in beta, so you load it yourself in Chrome. No store account needed.

Download BulkGen (zip)

Free and open source. View the code on GitHub

  1. 1 Unzip the download to a folder you will keep.
  2. 2 Open chrome://extensions and turn on Developer mode.
  3. 3 Click Load unpacked and choose the folder.
  4. 4 Open your Flow project, click the BulkGen icon, paste your prompts and press Start.

Questions

Does it use my Google password?

No. It works inside the Flow tab you are already signed in to. It never asks for or stores a password.

Who pays for the videos?

Your own Flow credits, the same as generating by hand. A 6 second clip with Omni 1.1 Flash cost 10 credits when we tested. Set a credit cap and anything pricier is never sent.

Why does Chrome say it is debugging the browser?

Flow ignores clicks sent by scripts on its Start and Download buttons, so BulkGen uses Chrome's debugger permission to send real clicks. Chrome shows a banner while a run is active. It goes away when the run ends.

Can I leave my computer while it runs?

Yes, but keep Chrome open and the computer awake, with the Flow tab left in place. The run lives in that tab.

Is it free?

Yes. BulkGen is free and open source under the MIT license. The code is on GitHub.

Is it made by Google?

No. BulkGen is an independent tool. If Flow changes its page, the extension may need an update.
